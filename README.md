# Jian Zhong

Personal academic website: [zhongwishing.github.io](https://zhongwishing.github.io/).

- Profile and site settings: `_config.yml`
- About section: `index.html`
- Education, internships, publications and contact links: `_data/`
- Typography and layout: `_sass/` and `css/`
- Photos, paper figures and logos: `assets/`

Run locally with `bundle exec jekyll serve --baseurl '' --disable-disk-cache`.

Pushes to `main` build and publish the site through GitHub Actions. In repository settings, Pages must use **GitHub Actions** as its source.

Based on Tufte-Jekyll. Theme and font licenses are included in `LICENSE` and `fonts/et-book/LICENSE`.
